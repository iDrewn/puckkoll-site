# Puckkoll

Website for **Puckkoll**, an iPhone app for following SHL and SDHL hockey: schedule, live scores, tables, goal notifications, Live Activities, an Apple Watch app and Tipset to tip with friends (iOS 26 and later).

Live site (once Pages is switched on): https://idrewn.github.io/puckkoll-site/

- [Home](https://idrewn.github.io/puckkoll-site/)
- [Privacy policy](https://idrewn.github.io/puckkoll-site/privacy.html) · [Integritetspolicy](https://idrewn.github.io/puckkoll-site/integritet.html)
- [Support](https://idrewn.github.io/puckkoll-site/support.html)

The site is plain HTML and CSS, published with GitHub Pages from the `main` branch. The clubs on the front page are drawn in CSS the same way the app draws its badges: a dark puck with the club's colours as three stripes. The puck in the hero slides in once, unless the visitor prefers reduced motion. The app itself lives in a private repository. Report problems or ideas for the app through this repository's issues.
